인스펙터 편의성 강화: [Tooltip]을 사용해 유니티 에디터에서 변수 설명을 바로 볼 수 있게 확인

- 무적 시스템 설계 변경. (Item → Skill)
- 기존에는 무적 아이템 획득 시 즉시 효과가 발동되고 사라지는 방식이지만 이젠 아이템 획득 시 '무적 스킬'을 보유하게 되며, 플레이어가 원할 때 [E] 키를 눌러 능동적으로 사용하도록 변경하도록 했어.
 
- 독립적인 스킬 관리 (InvincibilitySkill 스크립트 구현)
   1. 기존 Player 스크립트에 뭉쳐 있던 로직을 별도의 InvincibilitySkill 스크립트로 분리하여 단일 책임 원칙(SRP) 적용
   2. IEnumerator(코루틴)를 활용해 무적 지속 시간 동안 색상 변화 및 무적 상태 유지 로직 처리
   3. CanUse() 함수를 통해 쿨타임과 현재 실행 여부를 동시에 체크하는 방어적 로직 구현


- UI 참조 버그 수정 및 하이어라키 최적화
   1. GameObject.Find() 사용 시 이름이 같은 '검 스킬'과 '무적 스킬'의 UI(CooldownOverlay)가 충돌하여 엉뚱한 아이콘이 반응하는 문제 발생
   2. GameObject.Find()로 부모(Icon)를 먼저 찾은 뒤, transform.Find()로 자식 UI를 찾는 방식으로 수정하여 참조의 정확성 확보!
   3. SwordWeapon 스크립트의 SwordSkillIcon UI와 InvincibilitySkill의 아이콘 양쪽 모두에 이 방식을 적용해 시스템 간 간섭 차단 (SwordSkillIcon을 복사해 이름을 변경해서 무적 아이템 스킬 아이콘 추가)


- [Tooltip]속성을 적극 활용해 유니티 인스펙터에서 변수의 역할을 명확히 표기.
- 인스펙터에 변수 이름에 마우스를 올려두면 [Tooltip]에 적인 내용을 보여줘서 이 변수가 뭔지 이해하기 쉽게!
- InvincibilitySkill 스크립트에도 CheckInitialization() 함수를 통해 실행 시점에 누락된 참조를 로그로 알려주는 방어적 프로그래밍 적용.

126회 헌혈
무적 아이템 사용시 들릴 사운드 추가
게임 시작 카운트다운때 검공격,무적 아이템 사용 입력 제한 로직 구현

- 먼저 InvincibilitySkill 스크립트의 사운드 변수를activationSound → invincibilitySound 으로 이름을 변경. (가독성 및 명확성 확보)
- 캡슐화(Encapsulation) 원칙 적용: Awake() 에서 자동으로 할당되는 UI 관련 변수(cooldownOverlay, cooldownText)들을 private으로 전환, 인스펙터에서의 불필요한 노출을 줄여 작업 효율을 높이고, 외부 접근에 의한 잠재적 오류를 차단.
- 플레이어 오브젝트의 자식으로 SND_Invincibility 오브젝트를 만들어 이곳에 오디오 소스를 추가, output에 SFX 믹서를 연결

- 카운트다운 중에(Time.timeScale = 0)에도 키 입력이 먹혀서 무적 스킬이 발동되는 버그 해결.
- Update() 함수에 CountdownManager.isCountdownFinished 플래그를 활용해 AttackController와 InvincibilitySkill의 입력을 제어.
   1. if (CountdownManager.isCountdownFinished && Input.GetKeyDown(KeyCode.E) && CanUse())
        {
            ActivateSkill();
        }


- 검 공격도 무적과 똑같이 카운드다운 중에도 공격 모션이 발동돼.
- 해결도 무적 아이템과 거의 동일해. 
   1. 문제: 게임 시작 카운트다운 중에 검 공격 키(Q)나 무적 키(E)를 누르면 모션이 멈추거나 스킬이 미리 발동
   2. 원인: Time.timeScale이 0이어도 유니티의 Input은 계속 작동하기 때문이야
   3. 해결: 각 컨트롤러의(검 공격은 AttackController 스크립트) Update 함수 내 입력 로직 앞에 if (!CountdownManager.isCountdownFinished) return; 조건을 추가하여 게임 시작 전 입력을 차단


- 오늘 126회 헌혈을 했어. 시작한지 벌써 5년하고 10개월째야. **헌혈 많이 했다고 가산점은 없겠지만 최소한은 난 아무런 가치가 없는 사람이 아니라고 증명하는거야, 이런 나라도 누군가에겐 큰 도움이 되는 사람이라고**
